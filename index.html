02 — Git Commands Practised

Click any card to see it executed in the terminal below

git branch branching
Create, list, rename and delete branches. The foundation of parallel development.
git branch feature/login
git checkout navigation
Switch between branches or restore working tree files.
git checkout -b feature/login
git commit snapshot
Record staged changes as a snapshot in the repository history.
git commit -m "feat: add login"
git revert undo
Create a new commit that undoes changes from a previous commit safely.
git revert HEAD~1
git fetch remote
Download remote changes without merging them into local branches.
git fetch origin
git merge integration
Join two or more development histories (branches) together.
git merge feature/login
git pull sync
Fetch and integrate changes from the remote branch (fetch + merge).
git pull origin main
git push sync
Upload local branch commits to the remote repository.
git push origin feature/login
git branch -m rename
Rename a branch locally and update the remote tracking reference.
git branch -m old-name new-name

03 — Branching Workflow

Visual representation of the branch lifecycle practiced in this project

Branch graph — git log --oneline --graph --all
main
← HEAD (merged)
feature/login
→ PR #2 (merged)
feature/dashboard
→ PR #3 (open)
hotfix/nav-bug
→ PR #4 (reverted)
1
Create a feature branch
Always branch off from main. Use a descriptive name prefixed with the type (feature/, hotfix/, chore/).
git checkout -b feature/login
git branch --show-current
2
Stage, commit and document changes
Use atomic commits with meaningful messages. Stage specific files or hunks to keep commits focused.
git add src/auth.js
git commit -m "feat(auth): implement JWT login flow"
3
Push upstream & open a Pull Request
Push the branch to origin, then open a PR for code review. The PR includes a description, linked issues and reviewers.
git push -u origin feature/login
# Open PR on GitHub UI or CLI: gh pr create
4
Review, merge and clean up
After approval, merge the PR (squash or merge commit). Delete the remote and local branch afterwards.
git checkout main && git pull origin main
git branch -d feature/login
git push origin --delete feature/login
5
Revert a bad commit safely
When a commit introduces a regression, use git revert (not reset) to create a safe undo commit that preserves history.
git log --oneline -5
git revert e4f5g6h
git push origin main
